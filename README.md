# 长夜安魂曲

> 美术：武侠风试作（indigo 夜空、朱砂、飞檐、侠客夜行衣）。玩法致敬 iOS《安魂曲》（Never Gone）。

浏览器 **2D 横版动作清版**。技术栈：**Vite + TypeScript + Canvas 2D**。角色/场景/粒子代码绘制，音效与 BGM 由 WebAudio 合成。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc + vite → dist/
npm run preview    # http://localhost:4173
```

```bash
npm run shots
npm run test:parry
```

## 养成 Meta v3（无等级 / 无属性加点）

存档键仍为 **`requiem-save-v1`**，`version: 14`（多幕解锁 `unlockedAct` / `clearedActs`；兵刃实例 + `equippedWeaponUid`；自动迁移）。旧档 clears>0 视为四幕全开。v1/v2 自动迁移：剥除等级/经验/属性点，永久商店等级折算为材料，已购武器保留为已拥有+已知图纸。

### 货币与材料
- **血晶**：软通货（锻造/鉴定/炼丹/打坐手续费）。击杀、弹反、清场、通关获得。
- **材料**：精铁、兽骨、朱砂、灵草、玄铁、妖核 — 击杀掉落，堆叠于行囊。

### 山门面板
| 页签 | 内容 |
|---|---|

| **丹房** | 丹方炼制 + **出征四槽配丹** |

### 兵器锻造（图纸）

| 武器 | 获取 |
|---|---|
| 安魂银刃 | 初始已有 |
| 血棘短剑 / 圣银刺枪 / 断罪巨斧 | 图纸掉落 → 铁匠锻造 |
| 月蚀双刃 | 精英场图纸（或掉落）→ 锻造 |
| 葬钟大剑 | 首通首领保证图纸 → 锻造 |

战斗数值手感与武器克制与先前版本一致；品质（凡→极）略增伤/破势。

**v13 兵刃实例**：同一图纸可反复锻造，每次向 `gearBag` 推入独立 `GearItem`（`kind:'weapon'`，自带 level/quality）。`equippedWeaponUid` 指向装备中的实例；战斗 `mods()` 读该实例的等级/品质。防具仍为掉落+鉴定，本版不可打造。

### 功法（分轨 · 1–5 阶）
| 功法 | 轨 | 解锁 | 成长 |
|---|---|---|---|
| **内劲** | 内功心法 | 打坐入门 或 秘籍掉落 → 1 阶 | **打坐**耗材料+血晶升阶 |
| 轻功 / 铁布衫 / 连环腿 / 破军 / 疗伤 | 武学·身法·绝技 | **仅秘籍掉落** → 1 阶 | **实战熟练度**满条自动升阶 |

**熟练度来源**：轻功←跳跃/二段跳；铁布衫←格挡承伤/挨打存活；连环腿←冲刺踢命中；破军←施放+破军期间破势命中；疗伤←施放/残血施救；击杀对已学武学 +1。
效果随阶缩放（如内劲怒气 12%→35%，铁布衫减伤 4%→12%）。掉落不会跳到满阶。
存档 `version: 4`：`skillRanks` + `skillProf`；v3 的 `skills[]` 迁移为各 1 阶。

### 内功心法（v5）
混元功 / 血影心法 / 清虚心法 / 裂山劲。切换须重修。武功伤害随层。外功键 I ≠ 连招 J。

### 丹药
回血丹、怒气丹、攻击香、清心散，以及爆发/续航/解控等战丹。

### 失败与通关
- 通关：全额血晶 + 通关奖励；保证葬钟图纸；额外玄铁/妖核。
- 失败：保留本局 **60%** 血晶；本局已入袋的材料/图纸/未鉴装备仍保留。

## 硬核格斗

局内资源与对抗层（不影响山门养成存档结构）：

| 系统 | 说明 |
|---|---|
| **体力 / 力竭** | 攻击、闪避、跳跃、持防消耗体力；空挥略耗。归零进入短暂「力竭」硬直，易受伤。地面站立回复最快。 |
| **护甲 / 破甲** | 装备部位提供护甲池；受击先削甲。甲破后「破甲」易伤与格挡削血加重。脱战缓回。 |
| **锋锐 / 崩刀** | 局内锋锐影响伤害。双方招架碰撞触发「崩刀」拼刀：按兵刃重量与招式强度定胜负，败方硬直。重击持防会「弹刀」猛耗体力与锋锐。回山门恢复锋锐。 |
| **硬直等级** | 轻 < 中 < 重；轻击不能洗掉更高等级硬直。 |
| **抓投** | `→↓+攻`（或贴近持防敌人按前+下+攻）破无限龟缩，短暂无视护甲。 |
| **霸体** | 重击收招 / 破军期间短暂霸体（轻击不打断）。 |
| **反击** | 打中敌人出招前摇时伤害与硬直加成。 |

### 操作补充
- 抓投：`→↓` + 攻（触屏：右/前 → 下 → 攻）
- 崩刀：双方攻击判定重叠时自动触发，无需按键

## 开局与身法（v9）

- **初始未持兵刃**：新存档兵刃槽为空（内部拳脚兜底，山门不展示「空手」）；安魂银刃等由图纸锻造/掉落解锁。
- **轻功** → 二段跳；**闪身步** → 冲刺闪避（及冲刺踢）。未习得时按闪/二段跳提示「未习…」。
- **气势**：原怒气条改名。击打积攒，满条约 +6% 武功；**已移除** U / 天绝一剑 / 血月·终焉 必杀。绝学仅保留指令外功（破军/疗伤等）。


## 兵器门类外功与内力（v10）

| 门类 | 兵器 | 外功（↓→攻 等） |
|---|---|---|
| 空手 | fist | **崩拳** ↓→ · **虎爪** ↓← · 拳掌爪连段 |
| 刀剑 | silver / thorn / twin / bell | **刀芒** ↓→ |
| 枪系 | spear | **刺枪诀** ↓→ |
| 重兵 | axe | **破军** ↓→（破势 buff） |
| 不限 | any | **疗伤** ↓↓ |

- **内力**：与体力分离。施放外功耗内力；内功心法阶提升上限与回复。清心散回内力。不足提示「内力不足」。
- 错误兵器匹配指令 →「需持某兵器」。身法（轻功/闪身步）不限兵器。
- 空手连段： jab → jab → 掌 → 爪 → 踹；↓+攻=开山掌，↑+攻=爪。
