## 2. 清了哪些硬回退

## 3. `isCore*Id` 处理

库外仍近乎零调用。各函数改为依赖 **从 `changye/seeds` import 的官方包字面量**（`CORE_*.some(id===)`），即「官方包 id 集」；框架用 `import { CORE_X }; export { CORE_X }`（再导出兼容，且提供本文件绑定）。

涉及：`isCoreMaterialId` / `Weapon` / `Pill` / `Talisman` / `Skill` / `Neigong` / `ArmorSet` / `WepAffix` / `Fragment` / `Title` / `Affix` / `EliteMod` / `Enemy`。

## 4. 框架兼容 re-export（Oc5 可删）

以下框架文件**不再拥有**字面量，仅 `import`+`export` 或 `export { } from seeds`：

- `meta/{materials,weapons,alchemy,talismans,talismanScripts,animScripts,armorSets,weaponInstAffix,runFragments,titles,skills,neigong,gear}.ts`
- `meta/bTier/{coreData,weaponLookData}.ts`（`coreData.ts` 整文件变 stub）
- `level/{stage,actPools,affixes,eliteMods}.ts`
- `entities/enemies/factory.ts`

**例外（避免循环依赖）**：`CORE_COMBAT_STYLES` **不**从 `playerMoves` re-export（seed 需 value-import `BLADE`/`BARE`）；smoke / changye 从 `content/changye/data` 读。

示范包 `qiangying`/`shixiang` 仍 `import { CORE_STAGES } from level/stage` → 经兼容 re-export 编译绿；**Oc5 再清硬 import**。
