## 如何在设计台点出一条可灌符

1. 打开设计台 →「做一套招式 / 符」或页签 **符效**。
2. 左侧积木点入 `banner` / `damageCone`（或其它 19 kind）；可填 `anim`（datalist 点 sealBurst 等）。
3. 玩法目录 → **符** → 新增；填齐雾名/传闻/材料消耗等；`scriptId` 选本卷符效 id。
4. 导出 → 下载 `content.json`（或入藏）；远程 enable 后 `applyContent` 先 script 再 add。
