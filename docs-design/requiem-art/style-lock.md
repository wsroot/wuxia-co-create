# 《长夜安魂曲》Style Lock｜风格锁定

> 项目：requiem-web｜受众：Game Art Director / Codex / 外包静帧  
> 媒介：2D 侧视 flat vector silhouette + procedural Canvas draw  
> **禁止**：像素风 / pixel art、二次元厚涂、仙侠金光盛世、写实照片、3D 渲染堆砌  
> 截图校验源：`wuxia2-01-title` / `wuxia2-02-combat` / `wuxia-03-hub`（1280×720）

---

## 一句话定位

**暗夜纸墨武侠侧视动作**：长夜 · 安魂 · 江湖；冷月、远山剪影、竹与灯笼；忧郁诗意——**不是**明亮仙侠。角色 = 剪纸 / 皮影纸人，武器 = 薄刃发光描边。

---

## Do（必须）

1. **剪纸 / 皮影轮廓**：整块色面 + 硬边剪影；头部可用白色面具圆盘，五官极简或省略。
2. **冷月主光**：主光来自画面**右上**冷月；灯笼仅为局部暖点缀（金/琥珀）。
3. **纸墨色板**：墨深蓝黑底 + 血红 + 暖金 + 月白 + 偶发青竹/建筑青绿（见 `palette.md`）。
4. **宋体 / 明体标题与 UI**：大标题「长夜安魂曲」白→血红渐变；菜单为**斜切平行四边形**按钮 + 细金线 underline。
5. **侧视 2D 相机**：角色、场景、UI 均按 side-on 构图；远景层为山门/屋脊/宝塔剪影。
6. **可读性优先**：游戏内纸人目标高度约 **48–64px**；武器刃口用细发光边保证辨认。
7. **程序化战斗体**：正式战斗角色与攻击 FX **以 Canvas 几何/粒子为准**；图生仅作概念参考或静态道具剪影可选本地 sprite。
8. **山门 Hub**：深蓝纸板面板 + 金/红描边；物品卡需**剪影图标**，勿纯文字堆砌。

## Don't（禁止）

1. ❌ 像素精灵 / pixel art / 8-bit / dither
2. ❌ 二次元大眼、Q 版 chibi、厚涂写实脸
3. ❌ 明亮仙侠金碧辉煌、彩虹描边、多色 rim-light
4. ❌ 照片级 / 3D PBR / 复杂布料折叠
5. ❌ 把 UI 做成现代扁平 Material / 霓虹赛博
6. ❌ 用图生替代受击火花、斩击拖尾、格挡闪光、粒子、血条/怒气条、连击数字、刃口程序光晕（这些**留在代码 VFX**）
7. ❌ 发明截图中不存在的「已实装」美术事实

## 剪影比例（纸人角色画布指引）

| 项 | 规范 |
|---|---|
| 游戏内目标高度 | **48–64px**（概念稿可按 512–1024 高画，但需可缩到该高度仍可读） |
| 头:身（含帽） | 约 **1 : 3.5～4**（略拉长皮影感，勿 Q 版头大） |
| 头 | 黑帽 + 金缘细线；脸 = **月白面具圆盘**（#e8eef5），无五官或仅一线眼缝 |
| 躯干 | 整块深蓝袍面（#1a1c2c～#2a2e38），腰间 **血红/绛红束带** |
| 肢厚 | 剪纸条带感：上臂/大腿约头宽的 **0.35～0.45**；小臂/小腿略细；关节可硬折，勿肌肉圆润 |
| 武器 | **细长刃** + 外缘 **血红发光描边**（#e8455a）；柄短、色暗；刃宽在 48px 身高下约 **2–3px** |
| 敌人 | 同纸人逻辑；例：褐袍 + 红蒙眼；轮廓对比 PC 更「钝」、少金缘 |

概念参考画布建议：**1024×1024** 或 **768×1024** 单角色居中，透明或墨底，侧面站姿 + 1～2 动作剪影。

## 光照规则

| 规则 | 说明 |
|---|---|
| Key | **右上冷月**，月白/冷青白，强度克制 |
| Accent | **暖灯笼**仅点状（#f5a623 / #d4af37），竹丛与檐下偶见 |
| Fill | 极弱墨蓝环境光，禁止把暗部抬成灰雾一片 |
| 禁止 | 彩虹 rim-light、双侧霓虹轮廓、高饱和多色环境光 |
| 战斗特效光 | 刃光/受击用血红与月白短闪，由**代码粒子**控制，不进贴图 |

## 字体与 UI

- **标题**：宋体 / 明体 serif；「长夜安魂曲」**左大字**，白→血红纵向/斜向渐变（#e8eef5 → #c41e3a）。
- **菜单**：斜切平行四边形按钮；文字月白；底边 **细金下划线**（#d4af37）。
- **面板**：暖纸墨感深海军蓝填充（#0a0f1a / #1a1c2c），金或血红细边；Hub 后景可隐约月 + 宝塔剪影。
- **战斗 HUD**：红 HP、金怒气；关卡名如「山门古道」用宋体小标题。
- **禁用**：无衬线黑体作主标题、卡通气泡框、玻璃拟态。

---

## 相机

- 全程 **side-on 2D**；远→中→近景分层剪影（山/屋脊/竹 → 建筑 → 角色）。
- Title：左标题、右上冷月、江南屋脊/塔/桥剪影、稀疏散落暖灯、菜单旁可有持细红刃小纸人。
- Combat：左右对峙侧视；粒子（粉瓣、蓝珠）稀疏点缀，勿喧宾夺主。
