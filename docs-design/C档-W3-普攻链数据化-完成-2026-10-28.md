## 身份比较如何改成数据键

| 原 | 现 |
| --- | --- |
| `def === PM.plunge` | `hasCombatCue(def, 'plunge')`（盒上 `combatCue`） |
| `def === PM.rising` / `PM.launcher` | 同上 `rising` / `launcher` |
| `d === PM.finisher \|\| … \|\| name==='dashKick'`（剑气） | `d.swordQi` |
| `GROUND_CHAIN.includes(d)` / `d === BARE.kick` | `style.groundKeys.includes(name)` / `noChainOpen.includes(name)` |
| `chooseAttack` 直接 `return PM.launcher` | `mustAttack(style.branches.groundUp)` → `getAttackBox` ?? `SEED_BY_NAME` |

## 链如何数据化（结构）

```ts
AttackChainStyle {
  id: 'blade' | 'bare';
  groundKeys: string[];           // 普攻四/五连 attackKeys
  branches: { dash, groundUp, groundDown, airDown, airUp, airNeutral, finisherPoise?, finisherDrain?, throw };
  noChainOpen: string[];          // 结束后不开链窗
  plungeWaveKey?: string;
}
```

- bare / blade 两套示范：`BARE_CHAIN_STYLE` / `BLADE_CHAIN_STYLE`
- 选招：`chainStyleFor(isBare())` → 只读 keys → `resolveAttack`
- 换链：改 Style 表（或日后内容包挂同结构）；**无需**改 `player.ts` 常量比较
