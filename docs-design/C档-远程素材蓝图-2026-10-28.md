## 终点（用户）

新「箭种 / 弹幕模板 / 图集登记 / 音效别名（± 幕氛围）」= 内容包只登记数据：

- `projectiles.add`（`ProjectileDef`：闭集 `drawKind` + 碰撞/寿命/音效软引用）
- `volleys.add`（`VolleyDef`：闭集 `style` + 默认参数）
- `sheets.add`（`SheetDef`：`src` 须 `./art/`；禁外链；体素限额）
- `sfx.add`（`SfxDef`：`synth` 核心合成器 **或** 包内 `src`+`format`）
- （附）`backdrops.add`（`BackdropDef`：闭集 `theme` + 可选色板）

远程 `content.json` / 设计台导出同构可灌。  
**默认不扩** `ProjDrawKind` / `VolleyStyle` / `BackdropThemeId` / 新音频原语。  
禁止任意 JS / Canvas / **外链 URL** / **自由 PNG**（sheet/sfx 仍 `./art/` 白名单）。

对照：X1/F1/B1/G1 已通「先打通远程注入面」；本线是剩余 B 档素材四键（+ 可选幕氛围）同型债。

## 边界（与已闭环 P / W / F / T / B / A / X / G）

| 线 | 管什么 | 本蓝图 |
| --- | --- | --- |
| **远程素材专线（本单 R）** | 四键 ± backdrops：远程灌 / 设计台编导出 / 示范 / `./art` 限额 | 分期 R1–Rn |
| **fxRecipes + poses（X1–X5 已收口）** | 姿态/粒子配方远程+设计台 | **不抢**；可软引用核心 `recipeId` / pose |
| **功法 F / 符咒 T** | castAnim / ScriptStep（含 `sfx`/`spawnVolley`） | **不顺手改** ScriptStep 语义；本线只让其依赖目录远程可灌 |
| **武器 W + CombatStyle** | Style / looks；`WeaponDef.sprite.sheetId` → sheets | **不抢** W 语义；本线补 sheets 远程交付面 |
| **Behavior / bodyAttacks（B/A 已收口）** | `rangedAttack.projectileId` → projectiles | **不抢** Behavior；本线补 projectile 远程可灌 |
| **Boss 去壳（G1–G5+G2 已收口）** | bossMoves / kit | **不抢**；fireball 投射与 Boss 本地路径边界另点 |
| **机体积木 P0–P3** | Collider / 组装 | **不重开** |
| **设计台玩法副目录（债 #2）** | eliteMods/titles/… | **另线**；本线只补素材五键台面 |

共用但本线只打通交付 / 软引用：

- Behavior：`rangedAttack.projectileId` → `getProjectile`（缺 → arrow + warn）。
- ScriptStep：`sfx` → `getSfxDef`（synth）；`spawnVolley` → `getVolley`（`volleyId` 或 `style`）。
- 武器绘制：`sheetId` → `getSheet` / `getWeaponSheet`（`src` 相对路径加载；禁 `http`）。
- 场景：`g.backdropTheme` → `getBackdrop` → `theme` 选核心生成器 + 可选 `skyTint`。

### 1.5 消费点（解释器 / 绘制）

| 调用 | 文件 | 行为 |
| --- | --- | --- |
| 投射实体 | `entities/projectile.ts` | `getProjectile(kind)` → drawKind / hit 盒 / life / 爆炸与 `explodeSfx`；缺则按 kind 名回退 arrow/fireball |
| 杂兵远射 | `behaviorInterp.ts` | `rangedAttack.projectileId`（缺省 `arrow`）；目录无货 → warn + 用 arrow |
| 符 `spawnVolley` | `talismanScripts.ts` | `volleyId` 或 `style` → `getVolley`；无 style soft-skip |
| 符 `sfx` | 同 | `getSfxDef`：有 `synth` 则 `playSfx`；无 def 仍试历史名；**包内 `src`：注释写明 reserved / synth-only for now** |
| 兵刃贴图 | `weaponSheets.ts` | `getSheet` → 相对 `src` `Image()`；禁 `http`；未知 soft-skip → 程序刃 |
| 幕氛围 | `render/scene.ts` | `getBackdrop(g.backdropTheme)` → `theme` + 可选 `skyTint`；缺则用 theme 字面量 |
| 关卡字段 | `stage.ts` / `StageSchema` | `backdropTheme: string`（四幕核心 night/dock/ash/eclipse） |

解释器 **无** 按内容 id 的特判分支（仅 drawKind / style / theme 白名单）。  
旁注：`ProjectileDef.hitSfx` 已在类型/种子出现，命中路径**未见**统一消费（爆炸侧用 `explodeSfx`）——轻债，勿当 R1。

### 1.6 `./art/` 白名单与远程包边界（关键）

| 规则 | 证据 |
| --- | --- |
| sheet/sfx `src` 须 `/^\.\/art\//` | `services.ts` `ART_SRC_RE` |
| 禁外链 | `://` / `https?` → TypeError；`getWeaponSheet` 遇 http 返回 null |
| 馆入藏 `.tgz` **仅** `pack.json` + `content.json` | `dlc-server/UPLOAD.md` |
| 远程 enable 只拉 `content.json` 进 `applyContent` | `remote.ts` `loadRemoteDlc` |
| 游戏图集文件在 **游戏静态** `public/art/…` | 官方六张已随客户端 |

→ **远程 alone 能可靠验收的**：纯数据键（projectiles / volleys / backdrops / **synth-only** sfx）+ sheet **指向游戏已有** `./art/weapons/*.png` 的别名登记。  
→ **远程 alone 做不到 / 暂缓**：往馆包塞新 PNG/音频文件并被游戏解码；sfx 包内文件播放路径尚未实现（ScriptStep 注释 reserved）。

本线 R1 **不**扩「远程二进制素材通道」；新 PNG 仍走游戏仓 `public/art/` 或 Cordis 本机包（与现白名单一致）。

### 1.7 设计台：能否编导出？

| 表面 | 现状 |
| --- | --- |
| `designer-schema.json` 顶键 | **无** `projectiles` / `volleys` / `sheets` / `sfx` / `backdrops`（有 poses/fxRecipes/attacks/…） |
| `state.content` | **无** 五键（有 attacks…stages） |
| `buildContentExport` keys | **无** 五键 |
| `LIST_KEYS` / `emptyDef` | 无五键分支 |
| 关卡 `backdropTheme` | stages 字段**有**（枚举四 theme）；**不是**可编 `BackdropDef` 目录 |
| ScriptStep `sfx` | 步骤 kind 有；只写核心 id 字符串，**无可编 sfx 目录** |

结论：作者无法在设计台新建自定义箭种/弹幕/图集/音效目录/幕氛围目录；只能手写 Cordis 或改核心种子。

## 3. 目标态

| 角色 | 做 | 不做 |
| --- | --- | --- |
| **内容包** | 四键 ± backdrops `add`；Behavior/符/武器/关卡软引用；远程 JSON 同构（纯数据 + synth / 已有 art 路径） | 不改飞行循环/弹幕原语实现；不扩 drawKind/style/theme；不挂任意 JS/Canvas/外链/自由 PNG |
| **A 核心** | 单一目录 + 既有解释器；缺 id soft-skip / arrow·synth 回退 | 不按内容 id 开分支；不为「多一种箭头颜色」开新 drawKind（可用参数/既有 kind） |
| **C 档** | 仅当缺飞行/弹幕/幕生成器原语时扩闭集 | 不为「远程灌已有目录」开 C 原语单 |
| **设计台** | 能编四键 ± backdrops（闭集 + 参数）并导出；datalist 弱挂到 behavior/script/weapon/stage | 不做自由贴图上传器、不做完整音频预览器、不开放外链 URL 输入 |

目标句：**加一条「墨箭别名 / 慢雷弹幕 / 合成音效别名（± 蚀月色板）」= 登记目录 + 软引用；零战斗原语 diff；设计台导出 → 馆 enable 可灌（纯数据路径）。**

### R1 一次灌四键的理由（摸底）

1. **同型卡点**：Schema / Service / CORE / Cordis 登记**已齐**；唯一缺口与 X1 相同——`DlcContentBody` + `REMOTE_DLC_INJECT` + `applyContent`。  
2. **相互独立**：四键无交叉 Schema 依赖；注入只需相对「消费者」提前（behaviors / scripts / weapons）。  
3. **分批成本更高**：四次烟测/文档重复，收益仅「更小 diff」，而单次 diff 仍是类型三处对称改。  
4. **验收分层写进 R1**：以 **projectiles + volleys**（纯数据）为主断言；sheets/sfx 用「已有 art 路径别名 / synth 别名」证明灌通，**不**把新 PNG/包内音频当 R1 必过。  
5. **backdrops**：同型纯数据；**建议 R1 附带**（与债 #8 合并），若 diff 纪律要极瘦则 **R1.5** 单刀——须在完成单写明取舍。

设计台字段面：projectiles/volleys ≪ sheets（路径校验文案）≪ 完整音频；故 **R2 先箭+弹幕，R2b 再 sheets/sfx/backdrops**。示范 **R3+**。
