## 0. 一句话模型

| 层 | 做什么 | 谁改 |
| --- | --- | --- |
| **闭集白名单（kind / theme / style…）** | 允许哪些「积木种类」 | 核心 Schema + 类型；扩表属 **C 档** |
| **目录（catalog）** | 用积木拼出的配方 id（攻击盒、剪影、符效…） | 门派 / 内容包 / 远程 `content.json` / 设计台导出 |
| **解释器（interpreter）** | 读积木 → 改物理/伤害/粒子/绘制/音效 | **必须留在核心**；插件禁任意 JS/Canvas/URL |

框架目录初始为空；官方可玩内容由门派「长夜」`src/menpai/core` 灌种。读档侧统一经 `src/meta/contentRegistry.ts`（`getXxx` / `listXxx`）。

## 1. 白名单积木种类（闭集）

每类：**合法值 / 关键字段** → **登记入口（Schema → Service）** → **运行谁消费**。  
未知 kind：**登记拒收**（Schema/`validate*`）；若漏网则多数运行路径 **soft-skip + warn**。

### 1.1 ScriptStep（符效 timeline / 外功 castFx · **19 kind**）

| 组 | kind |
| --- | --- |
| 节奏/文案 | `wait` · `banner` · `float` |
| 观感轻量 | `fx` · `shake` · `hitstop` · `flash` · `sfx` |
| 伤害几何 | `damageRadius` · `damageCone` · `damageBox` · `damageDonut` |
| 连段/召击 | `multihit` · `spawnVolley` · `knockback` |
| 状态/场域 | `status` · `zone` · `pull` · `root` |

- **字段要点**：`fx.preset` ∈ `flare|ring|spark|qi|fire|dust|swordQi`（可另挂 `recipeId`→`fxRecipes`）；`spawnVolley.style` ∈ `skySword|thunder|waterPulse`（可另挂 `volleyId`）；`multihit.step` 只能嵌 `damage*` 四类；`damageBox` w/h/ox/oy；`damageDonut` rInner/rOuter；`zone` circle|box + duration/tickDamage。
- **登记**：`STEP_SCHEMAS` + `validateSteps`（`src/plugins/schemas.ts`）← `TalismanService.script` / `SkillService.add`（castFx）（`src/plugins/services.ts`）。
- **类型源**：`src/meta/talismanScripts.ts` `ScriptStep`。
- **消费**：`TalismanScriptPlayer`（同文件）逐步执行；功法施放与敌人负载符同播此套。`sfx` → `playCatalogSfx`。

### 1.2 AnimStep（观感时间轴 · **不造成伤害** · ~50 kind）

闭集见 `ANIM_STEP_KINDS`（`src/meta/animScripts.ts`）：

- 基线：`wait` / `playPose` / `holdPose` / `afterimage` / `weaponTrail` / `swingArc` / `sealGlyph` / `inkBurst` / `tintCaster` / `sfx`/`flash`/`hitstop`/`shake` / `hop`/`bounce`/`hover`/`fallStrike`
- 外功向：`dash`/`face`/`scalePunch`/粒子桥/`camZoom`/`slowmo`/`parryFlash`/`guardGlow`/`chainPose`/`loopPose`/`pullIn`/`orbitRing`/`beamLine`/`crescentSlash`/`groundCrack`/`riseMist`
- 符面向：`sealPaper`/`sealStamp`/`sealSpin`/`sealRain`/`sealChain`/`talismanTrail`/`inkSplash`/`baguaRing`/`runeOrbit`/`paperBurn`/`exorcismWave`/`bindThreads`/`soulBell`

- **登记**：`ANIM_STEP_SCHEMAS` + `validateAnimSteps` ← `AnimRecipeService.add`；技能 `castAnim` / 符 `anim` 亦可内联数组（登记时同样校验）。
- **消费**：`AnimScriptPlayer`（`src/meta/animScripts.ts`）。`playPose` 等软读 `ctx.poses`；`inkBurst.recipeId` 软读 `fxRecipes`；位移只改 `vx/vy/x/noGravity`（夹值）。可与 `castFx` **同播**。

### 1.3 BehaviorStep（杂兵 AI · **18 kind**）

`BEHAVIOR_STEP_KIND_LIST`（`schemas.ts`）：

| 层 | kind |
| --- | --- |
| 基线 | `keepDistance` · `meleeAttack` · `rangedAttack` · `block` · `charge` · `useLoadout` · `idlePace` · `facePlayer` |
| C 扩 | `dodge` · `circleStrafe` · `flank` · `callAlly` · `phaseAtHp` · `phaseGate` · `comboChain` · `retreatBurst` · `taunt` · `idleEmote` |

- **字段要点**：`meleeAttack.attackKey` → `ctx.attacks`（缺 soft-skip）；`rangedAttack.projectileId` → `ctx.projectiles`；`dodge.direction` ∈ `away|side`；`callAlly.enemyId` 软引用；`phaseGate` 可嵌套 `steps`。
- **登记**：`BEHAVIOR_STEP_SCHEMAS` + `validateBehaviorSteps` ← `BehaviorService.add`。
- **消费**：`tickBehaviorSteps`（`src/entities/enemies/behaviorInterp.ts`）加权选招 → 起攻击盒 / 射弹 / 位移 / 负载。

### 1.4 SilhouettePart（剪影部件 · **11 kind**）

`SILHOUETTE_PART_KINDS`：`headgear` · `torso` · `offhand` · `mainhand` · `palette` · `scale` · `cloak` · `armorLayer` · `ornament` · `faceMark` · `stanceBias`。

- **style 闭集（跨 kind 共用 lit）**：头饰 `bandit|hat|topknot|hood|none`；体 `robe|light|heavy`；副手 `blade|shield|none`；披风 `short|long|ragged|none`；甲 `plate|cloth|light`；饰 `pendant|sashKnot|banner|bell|feather`；面纹 `scar|mask|veil|none` 等（见 `SilhouettePartSchema`）。
- **登记**：`SilhouetteSchema` ← `SilhouetteService.add`。
- **消费**：杂兵 `resolveSilhouetteLook` + `drawSkeleton`；Boss 石兽 **只** `drawGargoyle` soft 读子集（`palette`/`scale` + `faceMark`/`ornament`/`armorLayer`/`cloak.color`）。**不**扩 kind 给包作者。

### 1.5 WeaponVisualPart（兵刃外观 · 另表闭集）

`WEAPON_LOOK_PART_KINDS`（`src/meta/weaponLooks.ts`）：结构 `grip|guard|tsuba|pommel|blade|tip|haft|head|chain|tassel|ring|twinOffset`；观感 `palette|inkEdge|glow|runeInlay`；FX 挂点 `idleTrail|swingHint|spriteOverlay`。

- **登记**：`validateWeaponLookParts` ← `WeaponLookService.add`；兵器可 `lookId` 或内联 `parts`。
- **消费**：`drawWeaponAppearance`（猎人 `drawHunter` 与敌人剪影共用）。

### 1.6 WeaponFeel（手感乘区 · 非 kind 枚举，字段闭形）

`WeaponDef.feel?`（`src/meta/weapons.ts` + `WeaponFeelSchema`）：

| 字段 | 含义 |
| --- | --- |
| `dmgMul` / `airDmgMul` | 全局 / 空中伤害乘 |
| `moveDmgMul` / `moveSpeedMul` | 按招式名乘伤害/速度 |
| `boxTune.tipXPush` / `tipWFloorMul` | 枪尖前推盒 |
| `boxTune.moveBoxWMul` / `moveBoxHMul` | 按招式名扩盒 |

- **登记**：随 `WeaponSchema` ← `WeaponService.add`。
- **消费**：`src/combat/weaponRuntime.ts` 组装命中盒时应用（**无** `shape===` 特判分支）。

### 1.7 BossMoveKind（Boss 招原语 · **10**；`perch`/`takeoff` 暂缓）

`claw` · `charge` · `fireball` · `dive` · `roar` · `walk` · `slam` · `sweep` · `summonAdds` · `inkNova`。

- **字段**：按 kind 可选 `radius`/`damage`/`hitstop`/`width`/`enemyId`/`count`/`side`/`frames`/`color`（`BossMoveSchema`）。
- **登记**：`BossMoveService.add`；kit 权重只引用已登记 **move id**（`BossKitService` soft-filter）。
- **消费**：`Gargoyle.chooseMove`（`src/entities/boss/gargoyle.ts`）按 kit 加权 → `kind` switch 切状态机；命中盒只 `getAttackBox`（G5）。

### 1.8 ProjDrawKind / VolleyStyle / SfxFormat / BackdropTheme

| 闭集 | 合法值 | Schema / 类型 | 登记 | 消费 |
| --- | --- | --- | --- | --- |
| **ProjDrawKind** | `arrow` \| `fireball` | `ProjectileSchema` / `bTier/types.ts` | `ProjectileService` | `entities/projectile.ts` 选绘制分支；伤害走 soft `attackKey`（缺省 fireball→`gFire`，其余→`arrow`） |
| **VolleyStyle** | `skySword` \| `thunder` \| `waterPulse` | `VolleySchema` | `VolleyService` | `TalismanScriptPlayer` `spawnVolley` 原语 |
| **SfxFormat** | `wav` \| `ogg` \| `mp3` | `SfxSchema` | `SfxCatalogService`（`src` 须 `./art/`） | `playCatalogSfx`：file buffer 优先 → synth → 历史裸名 |
| **BackdropTheme** | `night` \| `dock` \| `ash` \| `eclipse` | `BackdropSchema` / `BACKDROPS` | `BackdropService` | `render/scene.ts`：`getBackdrop` → `theme` 选核心氛围生成器 + 可选 tint |

## 2. 目录 / 注册表：数据怎么进、怎么查

### 2.1 Cordis services（唯一写入面）

实现：`src/plugins/services.ts`。插件 `ctx.<svc>.add(def)`（符效另有 `talismans.script`；幕池 `acts.pool` / `acts.beat`）。  
每条 `add` 挂在调用方 plugin scope：卸载则条目消失，同 id 下层恢复。Schema 不合格 → warn，不进目录。

权威服务表见 `docs/门派插件.md` §二（weapons…weaponLooks 等约三十项）。

### 2.2 contentRegistry（只读门面）

`src/meta/contentRegistry.ts`：游戏逻辑应 `getWeapon` / `getAttackBox` / `getBossMove` / `play` 辅助等，**不**直接碰 Cordis。  
注释明确：**解释器、战斗环、物理、存档格式、高风险 Boss 原语、新 ScriptStep/BehaviorStep/SilhouettePart kind** 仍属核心。

### 2.3 REMOTE_DLC_INJECT + applyContent

`src/dlc/remote.ts`：

1. 拉馆 `content.json` → Cordis fork（`inject: REMOTE_DLC_INJECT`）。
2. `applyContent` 按依赖序 `add`（poses/fxRecipes → sheets/sfx → projectiles→volleys → talismanScripts → attacks → animRecipes → skills → … → silhouettes/behaviors/colliders → bossMoves → enemies → backdrops → stages；**acts 禁止假灌 `add('acts')`**，走 `pool`/`beat`）。
3. 键表即 `REMOTE_DLC_INJECT` 数组（与 inject 依赖对齐；body 侧另含 `talismanScripts`）。

设计台导出同构 JSON，经同一 `applyContent` 可灌。

### 2.4 官方种子路径

`src/menpai/core/index.ts` 把 `CORE_*`（含 `meta/bTier/coreData.ts` 的 B 档表、`CORE_ANIM_RECIPES`、`CORE_SCRIPTS`、兵器/关卡等）登记进各 service。  
**种子内容可迁出为官方包**；**解释器与闭集枚举不可迁**。

## 3. 解释器：积木 → 行为（一句机制）

| 解释器 | 路径 | 机制（一句） |
| --- | --- | --- |
| **符效 Script** | `meta/talismanScripts.ts` `TalismanScriptPlayer` | 按帧推进 `ScriptStep[]`：文案/粒子/震屏 → 几何伤害/弹幕/状态场域 |
| **动画 Anim** | `meta/animScripts.ts` `AnimScriptPlayer` | 按帧推进 `AnimStep[]`：姿态/残影/符面/轻位移/镜头；**零伤害** |
| **行为 Behavior** | `entities/enemies/behaviorInterp.ts` | 每 tick 扫 `BehaviorStep[]` 加权挑行动 → 攻击盒/投射物/闪绕/呼援/相位 |
| **Boss chooseMove** | `entities/boss/gargoyle.ts` | kit close/far 权重抽 move **id** → 查 `bossMoves.kind` → 切石兽状态机；idle/walk 空档可先负载施放 |
| **战斗 resolver** | `combat/resolver.ts` `resolveHits` / `applyHit` | 互撞/打人/弹射命中：读攻击盒结算伤害/硬直/崩刀；可选 `hitSfx`→`playCatalogSfx` |
| **武器手感** | `combat/weaponRuntime.ts` | 把 `WeaponFeel` 乘进伤害与 hitbox 几何后再交给 resolver |
| **普攻链 Style** | `contentRegistry.resolveCombatStyle` + `combat/playerMoves` | `combatStyleId`→目录→category 默认→CORE 常量；链上 key 只认 `attacks` |
| **sfx** | `audio/sfxCatalog.ts` `playCatalogSfx` | catalog id：解码 buffer → synth → 历史裸名；否则 soft-skip |
| **投射物 draw** | `entities/projectile.ts` | `drawKind` 二选一画飞行体；命中键 `resolveProjectileAttackKey` |
| **弹幕 spawnVolley** | `talismanScripts` 内原语 | `style`/`volleyId` 选 `skySword|thunder|waterPulse` 生成器 |
| **剪影 draw** | `resolveSilhouetteLook` → `drawSkeleton`；Boss → `drawGargoyle` | parts 白名单改色/披甲/手持；手持再进 `drawWeaponAppearance` |
| **兵刃外观** | `render/drawWeaponAppearance.ts` | 解释 `WeaponVisualPart[]`（+ 可选 sheet 叠层） |
| **幕氛围** | `render/scene.ts` | `backdropTheme` id → `getBackdrop` → 核心 theme 生成器 + tint |
| **碰撞组装** | `ColliderService` + factory | 只写 Body w/h（及可选 gravityScale）；无自定义碰撞 JS |

## 4. 核心该留 vs 该迁到官方包

| **留在核心（扩表才动）** | **可迁 / 已是目录内容（官方门派或 DLC 包）** |
| --- | --- |
| 全部解释器实现（上表） | `coreData` / `CORE_*` 种子条目（具体 id 配方） |
| Schema 闭集枚举与 `validate*` | 兵器/丹/符/外功/内功/材料/防具/词缀/残页/称号… |
| 战斗环、物理、存档格式、沙箱限额 | B 档目录行：attacks/poses/projectiles/volleys/fx/sheets/sfx/silhouettes/behaviors/backdrops/bossMoves/animRecipes/weaponLooks/colliders/combatStyles |
| 高风险 Boss 原语状态机（dive/roar/…） | Boss **kit 权重行**、自建 move **id**（kind 仍须属闭集） |
| 新 ScriptStep / AnimStep / BehaviorStep / SilhouettePart / BossMoveKind / drawKind / VolleyStyle / theme | 用已有 kind **组合**出的新配方（示范包 moyu/qiangying/shixiang…） |
| sheet/sfx 路径与格式校验、体素/字节限额 | `./art/` 下具体资源文件（音频进游戏静态 `public/art/audio/`，馆 tgz 不塞二进制） |

产品口径：**作者只拼积木；要新动词（kind）找核心排期。**
