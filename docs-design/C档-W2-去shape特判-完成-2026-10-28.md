## 特判如何迁到 feel / 白名单

### spear tip（原 `shape === 'spear'`）

原逻辑：
```
box.x = base.box.x + Math.round(14 * reach);
box.w = Math.max(box.w, Math.round(base.box.w * reach * 0.92));
```

现：`feel.boxTune = { tipXPush: 14, tipWFloorMul: 0.92 }`  
解释器：若 `tipXPush != null` 则按上式推 tip；`tipWFloorMul` 缺省 0.92。

### axe 盒扩（原 `shape === 'axe' && finisher|slash1`）

原逻辑：`box.w *= 1.08`、`box.h *= 1.06`（仅 finisher/slash1）。

现：
```
boxTune: {
  moveBoxWMul: { finisher: 1.08, slash1: 1.08 },
  moveBoxHMul: { finisher: 1.06, slash1: 1.06 },
}
```

新武器只需挂 `feel`+数值即可复现 tip/axe 盒感，无需新 shape、无需改 runtime。

## affinity 新规则

`affinityVs` **只认**：

| 标记 | 效果 |
| --- | --- |
| `target.isBoss` 或 `target.kind === 'gargoyle'` | 若武器有 `bossGargoyle` / `antiArmor` → 对应亲和 |
| `target.kind === 'shield'` | `shieldBreak` |
| `target.superArmor` | `antiArmor` |

**不认**显示名字符串（「镇山石兽」「割喉者」等）。`name` 参数仍可传入但忽略。
