## tint vs palette

```
幕级 GargOpts.tint → skinMap → skin/skinB/dark/soft
         ↑ 无 palette 字段时全程有效
silhouette.parts palette.skin → 覆盖 skin（flash 时仍白）
palette.arm → skinB；无 arm 时 palette.coat → skinB
```
