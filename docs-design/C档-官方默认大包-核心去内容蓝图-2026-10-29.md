## 1. 目标 / 非目标（禁区）

### 目标

- **核心**只留：解释器 + Schema + 白名单原语（taxonomy / ScriptStep·AnimStep 闭集 / soft-skip 规则）。
- **出厂玩法与 B 档目录内容**全部迁入一个 **官方默认大插件包**（always-on），由包 `apply` 登记进 Cordis 目录。
- 框架目录启动时**可空**；有默认包才有「长夜」观感。可选包仍走 `OPTIONAL_*` / 远程 DLC。

### 非目标 / 禁区

| 禁 | 说明 |
| --- | --- |
| 任意 JS | 不 eval、不跑包内战斗脚本 |
| 任意外链 | `http(s)://` / `://` 继续拒 |
| 自由 Canvas / 自由 PNG | 不扩渲染主权；sheet `src` 仍 `./art/` |
| 把内容枚举永久塞进核心债 | 出厂 id 列表属包数据；Schema 闭集（如 `drawKind`）≠ 内容枚举 |
| 本蓝图阶段改码 | 不迁表、不接线、不抽空、不 bump、不部署、不跑 test/build |
| 并石兽状态机 / 扩 `drawKind` / #12 perch | **另债**（见 §5） |
| 把官方大包塞进 `OPTIONAL_PACKS` 当可关 DLC | 默认包须 always-on，与今日 `menpai-core` 同级 |

## 8. 已知限制

1. **活目录 vs 死 `CORE_*`**：`WEAPON_BY_ID` 等已是栈视图，但 `isCore*Id` / factory `CORE_ENEMIES.find` / 示范包 `CORE_STAGES` / smoke 长度断言仍钉死种子——Oc4 前不能「假抽空」。  
2. **设计台 `core*` 静态快照**：与运行包可能漂移；去内容后须约定「官方包 regen」或改名，否则 datalist 撒谎。  
3. **远程 alone 不足以替代 always-on 大包**：馆 JSON 对 B 档弱于 Cordis；出厂体验须客户端必载源插件。  
4. **双载风险**：`content/core` 遗留 + 新大包 + 旧 menpai-core 若并行 → id 层叠难查；Oc3 须单路径。  
5. **#12 perch / 扩 drawKind**：本线不开。
