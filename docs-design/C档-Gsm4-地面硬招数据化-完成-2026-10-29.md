## 示范 / smoke 怎么验可辨

1. **纯函数**：`windFramesFromMove(null, 38)===38`；`windFramesFromMove({…, windFrames:8}, 28)===8`；≤0 → fallback；999 → 180。  
2. **Cordis**：`slam_gsm4_wide` `radius:280` + `windFrames:6` → chooseMove → slamWind → 6 帧后 slam → `areaHit` rx=280 / damage=22。  
3. **sweep / charge**：`windFrames:5/4` → 对应帧数后进 active。  
4. **CORE**：omit `windFrames` → 38/28/22；slam radius/damage 仍为 140/18。  
5. 运行：`npm run test:menpai`（含 Gsm4 断言）。
