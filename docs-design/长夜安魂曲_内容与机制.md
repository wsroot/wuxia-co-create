## 一、游戏概览

### 1.1 题材与气质

- **一部横版武侠动作**：主角「夜行人」自长夜山门出发，在夜雨、客栈、荒冢、月蚀峰巅四幕中斩尽亡者，为镇守各地的石兽送上安魂一曲。
- **暗夜**：全程夜色，血月随首领战渐圆；第二阶段首领「狂怒」时月色转赤。
- **安魂**：安魂钟、安魂符、安魂目标、葬钟大剑、安魂铃绪……「为亡者安魂」贯穿器物、场地与目标。
- **纸墨武侠**：标题「江湖篇 · 月下刀光」，题辞「夜雨江南，剑气如霜。执刃之人，于江湖长夜中叩问刀心」。界面用语一律江湖口吻：拔剑夜行、叩山门、烛下辨物、开炉锻打、研墨绘制、打坐、重修、兑出。

### 1.2 核心循环

| 环节 | 玩家做什么 | 得到什么 |
|---|---|---|
| 山门备战 | 换兵刃与防具、装入丹药与灵符、打坐心法 | 出征前的整套配置 |
| 出征四幕 | 自所选一幕起，连闯至第四幕；每幕三处战场 + 一名首领 | 血晶、材料、图纸、未鉴装备、秘籍 |
| 首领宝箱 | 击败首领后 2～4 只品质宝箱围尸爆出，逐一开启 | 大量材料、血晶、未鉴装备、图纸 |
| 带回山门 | 胜利全额结算；败亡保留六成血晶，拾得物全数带回 | 养成资源入库 |
| 铸造·鉴定·强化 | 铁匠铺辨物、开炉锻打、淬炼与重锻；丹房炼丹；符箓绘符 | 更好的兵刃、防具、丹药与符 |
| 再出征 | 换上新装，再入长夜 | — |

### 1.3 养成哲学：无等级、无加点

- 角色**没有等级，也没有属性点**。一切变强来自四条线：**兵刃与防具**（打造、鉴定、强化、重锻）、**内功心法**（打坐升层）、**武学**（实战熟练度升阶）、**丹药与符箓**（出征消耗）。
- 武学秘籍与心法秘籍只能在夜行中掉落获得，不可购买。
- 防御类养成有上限：山门养成的「护体」最高 55%；局内叠加丹药、符箓后，减伤最高 65%。

### 1.4 开局状态

| 项目 | 初始内容 |
|---|---|
| 兵刃 | 空手（拳脚） |
| 心法 | 混元功 第 1 层 |
| 武学 | 无（闪身步、轻功等均需秘籍掉落获得） |
| 血晶 | 40 |
| 材料 | 精铁 4、兽骨 3、灵草 2、朱砂 1 |
| 丹方 | 回血丹 |
| 灵符 | 解控符 1 张（已领悟解控符） |
| 可选幕 | 第一幕；破一幕开一幕 |

## 二、战斗机制

### 2.1 基础操作（玩家说明口径）

| 动作 | 键盘 | 触屏 |
|---|---|---|
| 移动 / 跳跃 | A D 或方向键 / W、空格 | 摇杆 / 跳 |
| 攻击 | J | 攻 |
| 格挡（弹反） | K | 防 |
| 闪身 | L | 闪 |
| 外功快捷 / 处决 | I | 技 |
| 释放灵符 / 轮换灵符 | U / Y | 符 / 换 |
| 出征丹药四槽、幕间选项 | 1～4 | 丹槽按钮 |
| 临时符 | ↓ + I | ↓ + 技 |

### 2.2 资源条

| 资源 | 上限 | 用途与回复 |
|---|---|---|
| 气血 | 100（防具加成） | 归零即败亡；场地持续伤害不会致死（最少留 1 点） |
| 气势 | 100 | 闪身消耗；满气势时武功伤害约 +6%；不再有大招键 |
| 体力 | 100 | 出招、跳跃、闪身、格挡均耗体力；耗尽「力竭」 |
| 内力 | 60 + 心法层数×14 | 施放外功消耗；脱战与非攻击时回复较快 |
| 护甲 | 18 + 防具护甲 + 护体换算 | 吸收部分伤害；打空「破甲」；脱战缓慢回复 |
| 锋锐 | 100（五格） | 兵刃锋口；崩刀、被重击格挡、抓投会磨损，伤害随之降至最低 78%；每次出征重置 |

**气势**
- 被动缓慢回复；攻击中回复减为约三成半，格挡中约五成半。
- 普攻命中：每招 +4 起（重招 5～10），受「气势」加成与兵刃积势系数影响。
- 受击 +3，格挡 +2，完美弹反 +15（受加成）再额外返还 +8（清虚心法满层再 +6）。
- 获得气势时，同时微补内力（获得量的 15%）。

**体力消耗**

| 动作 | 体力 |
|---|---|
| 轻招 / 中招 / 重招 | 7 / 10 / 15 |
| 闪身 | 16（残势闪身 ×1.35） |
| 跳跃 / 二段跳 | 5 / 7 |
| 挥空 | 额外 3 |
| 抓投 | 18 |
| 格挡 | 持续消耗；挡下重击额外 14 |

力竭：约 0.6 秒无法行动，期间所受伤害 ×1.18。

**护甲与破甲**：护甲打空后进入「破甲」约 3 秒，所受伤害 ×1.28，格挡削血 ×1.55。

### 2.3 开局空手：王八拳

- 新角色手无兵刃，以「空手」拳脚应战：刺拳、刺拳、推掌、爪击、踢腿五段连打，近身乱打、破势弱。
- 空手是兜底，不在山门作为一件兵刃列出；卸下兵刃时自动回到拳脚。
- 空手同样可练空手外功（崩拳、虎爪、铁山靠、翻云腿），亦可锻造铁砂掌、虎爪套两件拳套类兵刃。

### 2.4 连招与分支

| 招式 | 输入 | 说明 |
|---|---|---|
| 地面连斩 | 连按攻 | 持兵刃：三段斩 + 终结；空手：五段拳脚 |
| 破韧终结 | 连斩第四段 | 霸体终结，破势 ×1.55，伤害略低 |
| 吸血终结 | 闪身踢后接攻 | 命中回复所造成伤害的 28% |
| 挑空 / 扫腿 | ↑ + 攻 / ↓ + 攻 | 挑空可接空中连斩；扫腿可打倒地之敌 |
| 冲刺踢 | 闪身中按攻 | 需闪身步；伤害随闪身步、连环腿提升 |
| 空中连斩 | 空中连按攻 | 一秒内持续命中可滞空连段 |
| 升空斩 / 下劈 | 空中 ↑ + 攻 / 空中 ↓ + 攻 | 下劈落地生冲击波 |
| 抓投 | → ↓ + 攻，或贴近缩防之敌按攻 | 不可格挡，破甲 |
| 反击斩 | 完美弹反后自动 | 威力 30 的重斩 |

- **武学精通加成**：刀芒、刺枪诀、崩拳、破军、开天斧、穿心枪、斩马刀、回旋斩任一练至第 3 阶，终结技伤害与破势/击退再增约一成。
- **连击评价**：3 连起评「尚可」，依次「凌厉」(8)、「华丽」(15)、「狂暴」(25)、「血舞」(40)、「剑心」(60)。

### 2.5 外功嵌入连招指令

外功以方向指令 + 攻发出（亦可按「技」快捷施放），施放耗内力、有冷却。指令按兵刃种类共用：

| 指令 | 不限兵刃 | 刀剑 | 枪 | 重兵（斧锤） | 空手 |
|---|---|---|---|---|---|
| ↓↓ 攻 | 疗伤 | | | | |
| ↓↑ 攻 | 凝气 | | | | |
| ↓→ 攻 | | 刀芒 | 刺枪诀 | 破军 | 崩拳 |
| ↓← 攻 | | 回旋斩 | 突刺 | 横扫 | 虎爪 |
| ←→ 攻 | | 斩马刀 | 穿心枪 | 开天斧 | 铁山靠 |
| ↑↓ 攻 | | | | | 翻云腿 |

手持兵刃不符时提示「需持某兵」，不出招。

### 2.6 格挡、完美弹反与崩刀

- **格挡**：正面挡下可格挡之招，仍受约 12% 削血并耗体力；挡下重击会「弹刀」，额外耗体力、磨锋锐。
- **完美弹反**：起手格挡的约 1/6 秒内被击中即为完美格挡——慢动作、短暂无敌、内力 +6、气势大增，敌人陷入「破绽」，夜行人自动反击斩；箭矢则被「反弹」。每局前 12 次弹反各得 1 血晶。弹反时机可被清虚心法、清心定魂套装、「稳锋」称号放宽。
- **崩刀**：格挡时错过弹反窗被重击，或双方刀刃相撞而己方兵刃较轻，即「崩刀」——硬直、锋锐大损；兵刃更重者「弹开」对手。
- **不可格挡**：盾兵冲撞破防；首领俯冲、俯冲冲击波、咆哮、抓投类攻击须闪避或跳开。

### 2.7 闪身耗气势

- 须习得「闪身步」才能闪身；未习时提示「未习闪身步」。
- 每次闪身耗气势 11，并有短暂无敌与冷却。
- 气势不足 3 时无法闪身；不足 11 时为「残势闪身」：无敌时间减半、冷却延长、体力多耗。
- 闪身冷却可被疾影残页、夜行残响套装、影步散、残月场地缩短。

### 2.8 敌招破绽窗与反击窗

敌人出招时头顶会标示读招窗口：

| 窗口 | 时机 | 你此时出手 |
|---|---|---|
| 抢攻 | 敌人起手早段 | 打断得「反击」加成：伤害 ×1.22、硬直更长 |
| 反击窗（红） | 临出手至出手初段 | 强行硬拼会被反噬：自身受伤（约为输出的 22%），输出只剩 72%，几乎削不动架势 |
| 破绽（金） | 敌招收势、被弹反、被破势、倒地 | 伤害 ×1.32、破势 ×1.4、硬直更长 |

精英与首领的反击窗更长，短招也有一瞬反击窗。

### 2.9 处决

- 敌人气血低于 22%（首领低于 18%）、或处于破势/被弹反破绽，且贴身时，屏幕提示「处决」，按「技」确认。
- 处决：一击伤害为目标气血上限 35%（至少 28），短暂无敌、气势 +12，伴慢动作与闪屏。
- 处决伤害受心法（混元、血影、裂山）与饮血罗刹套装加成；单局处决 5 次得称号「断罪」。

### 2.13 精英与首领架势条

- **精英架势**：精英头顶有短架势条（48）。打空即「破势!」，陷入约 0.7 秒破绽；若破势后未能斩杀，精英会「进化」（见第七章）。
- **首领架势**：首领架势 110 起（随幕加厚），第一阶段另有石甲；架势打空即「架势崩裂」，进入约 2.5 秒长破绽。首领久未受击会缓慢回架势；弹反首领一次削架势 40。
- **霸体**：首领气血降至一半进入「狂怒」——全程霸体（普攻打不出硬直），出招更快，架势上限提至 170；须靠破势或弹反制造破绽。夜行人的终结技、破军、开天斧、铁山靠、崩拳亦带短暂霸体。

## 三、武学

### 3.1 内功心法

- 同时只能修一门；**只能在山门「功法」栏切换**，夜行途中不可换。
- **切换即重修**：耗血晶 40，卸下的心法层数散尽归零（仍记得此门），新心法从第 1 层重练。
- **打坐升层**：只能为正在修的心法打坐，每层耗材料与血晶，最高第 5 层（大成）。
- 新心法只能由夜行中「心法秘籍」掉落获得（每次击杀约 1.5%）。

| 心法 | 风格 | 第1层 → 第5层 | 满级门派效果 | 获取 |
|---|---|---|---|---|
| 混元功 | 均衡 | 武功 +6%→+20%；气势 +8%→+22%；减伤 +2%→+6%；内力回复 ×1.0→×1.2 | 回内最快档之一；处决伤害 +10% | 初始 |
| 血影心法 | 烈攻 | 武功 +10%→+28%；气势 +10%→+24%；减伤 0→+2%；内力回复 ×1.05→×1.25 | 饮血：普攻吸血 4%；处决伤害 +18% | 秘籍 |
| 清虚心法 | 守中 | 武功 +3%→+12%；气势 +14%→+34%；减伤 +3%→+11%；内力回复 ×1.15→×1.55 | 完美格挡时机大幅放宽；弹反回气 +6 | 秘籍 |
| 裂山劲 | 霸道 | 武功 +12%→+35%；气势 +2%→+10%；减伤 +1%→+4%；内力回复 ×0.9→×1.0 | 破势伤害 +22%；处决 +8%；重击更沉 | 秘籍 |

### 3.2 外功

- 外功按**手中兵刃种类**激活：刀剑 / 枪 / 重兵（斧锤）/ 空手（拳掌爪），另有两门不限兵刃。
- **不设数量上限**：习得的外功全部可用，无需装配。
- 每门外功分 5 阶；阶数提升伤害并缩短冷却（攻击类：伤害 ×1.0→×1.3，冷却 16→12 秒）。

| 外功 | 兵刃 | 指令 | 内力 | 作用 |
|---|---|---|---|---|
| 疗伤 | 不限 | ↓↓攻 | 22 | 瞬回气血 22→36，冷却 24→18 秒；残血施放熟练更快 |
| 凝气 | 不限 | ↓↑攻 | 18 | 8 秒攻击 ×1.18，并回内力 12；冷却 14→10 秒 |

### 6.2 血晶

血晶是唯一货币，用于锻造、鉴定、强化、重锻、打坐、重修、炼丹、绘符、净秽与市集。

| 来源 | 数量 |
|---|---|
| 击杀 | 每杀 2 + 敌人气血上限 / 40（斧兵 3、盾兵 4、弓兵 3，精英更多）；约 18% 另爆血晶珠 3～5 |
| 完美弹反 | 每局前 12 次各 1 |
| 战场肃清 | 每处 15 |

| 邪气潮 | 潮汐箱 12 |
| 据点「辨物」 | 2 |
| 通关四幕 | 结算额外 +120 |
| 市集兑出 | 见下 |

**结算**：出征途中的血晶为「此行所得」；通关全额入库，败亡只保留六成。材料、图纸、未鉴装备一经拾得即算数，败亡也全数带回。

### 6.3 市集（交易市场）规则

- **兑出**：已辨认的兵刃、防具与材料可兑成血晶。
  - 装备价 = 品质底价（凡 6 / 良 10 / 优 18 / 极 32）+ 已投入强化血晶的 15%，远低于投入。
  - 未辨之物市集不收，须先到铁匠铺辨物。
  - 在手兵刃、在身防具不可兑出，须先卸下；只剩一把兵刃时不可兑出；空手不可兑出。
  - 优、极品质或已淬炼至第 3 重以上的装备，兑出前二次确认，兑出后无法赎回。
  - 材料单价：精铁、兽骨、兽皮 2；灵草、丝线、朱砂、煤铁 3；玄铁 8；灵玉 10；妖核 14。可单个或五个一兑。
- **购入**：市集常备全部十种材料，单价为兑出价的 2.5 倍（向上取整）：精铁、兽骨、兽皮 5；灵草、丝线、朱砂、煤铁 8；玄铁 20；灵玉 25；妖核 35。
- 山门其余各栏均无出售按钮，兑物只走市集。

### 7.5 精英词条与进化

- 战场中的敌人可能带精英词条：第一波 18%、之后各波 38%，按本幕精英偏好抽取。精英头顶标词条名，气血 ×1.45，带短架势条，掉落更好。

- **精英进化**：精英被破势后若未在破绽内斩杀，「余烬未散…」——稍后战场中会出现一只同类「进化」精英（气血再 ×1.25，架势更厚），同时最多排队两只。

主界面名为「长夜山门」，顶部显示血晶、材料总数与武功加成，概览气血、攻势、护体、气势、心法、兵刃；下方为四幕出发按钮（已破之幕标「破」），以及「拔剑夜行」「直闯镇山」「归至月下」。
