## 2. Boot API（Oc3）

| API | 说明 |
| --- | --- |
| `bootOfficialPack(config?)` | 显式、幂等加载 `Changye`（唯一出厂登记路径） |
| `unloadOfficialPack()` | **仅测** dispose；生产勿关后仍期望可玩空核 |
| `isOfficialPackLoaded()` | 长夜包是否在载 |
| `bootMenpaiOnly(opts?)` | `opts.officialPack !== false` 时调用 `bootOfficialPack` |
| `bootMenpai(extraMenpai?, extraPacks?, opts?)` | `bootContent` → `bootMenpaiOnly` → OPTIONAL |
| `CHANGYE_PACK_ID` | `'changye'`（Cordis 技术 id） |
| `CORE_MENPAI_ID` | `'core'`（商店/存档兼容展示 id，「长夜」） |

生产：`main.ts` 仍 `bootMenpai(menpaiFromUrl(...), packFromUrl(...))` → 默认开包，观感与 Oc2 一致。

## 3. 关包怎么验

```ts
bootMenpai([], [], { officialPack: false });
// → weapons/skills/stages/enemies/attacks/… length === 0（近空）
loadPack('hanmang'); // OPTIONAL 仍可叠
unloadPack('hanmang');
bootOfficialPack();  // → 长夜齐全（与 EXPECTED 计数一致）
```

Smoke 已覆盖上列（`Oc3:` 前缀断言）。亦可 `unloadOfficialPack()` 后再断言近空（本刀 smoke 用「先关后开」路径，未中途 unload）。

## 5. 已知限制 / 留给 Oc4+

1. **Oc4**：抽空框架侧 `CORE_*` 常量出口；清 `CORE_ENEMIES.find` 等硬回退；`isCore*Id` 改官方包 id 集或删；数组字面量物理迁入包内（现仅 barrel 汇出）。关包时死表仍在模块里，故称「近空」而非「源树无表」。
2. **Oc5**：示范包去掉硬 `import { CORE_STAGES }`；smoke 断言措辞全面改「官方包」；可选馆种子；设计台 `core*` 另刀。
3. **Config 写死出厂 id**（`jiekong`/`bell`/潮汐）：仍在 changye Config；后续可 soft。
4. **手动 `game.plugin(CoreMenpai)`**：仅得空壳 + warn，不会灌长夜——须改用 `bootOfficialPack`。
5. **硬壳另债**：Gargoyle 状态机、`drawKind` / body / BossMoveKind / synth 闭集 — 本线不迁。
