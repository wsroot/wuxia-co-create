## 终点（用户）

新武器 = 内容包只登记数据：外观配方 + 数值/手感 +（可选）引用既有招式盒 / 外功。

## 1. 链路图（谁吃哪本目录、谁解释）

| 层 | 数据入口 | 目录 / 类型 | 解释器 / 调用方 | 证据路径 |
| --- | --- | --- | --- | --- |
| **外观** | `WeaponDef.lookId` / `parts`；或 `ctx.weaponLooks.add` | `WeaponLookDef` + `WeaponVisualPart` 白名单 | `appearanceFromWeapon` → `drawWeaponAppearance`；猎人 `drawHunter`、剪影 `resolveSilhouetteWeaponLook` | `src/meta/weaponLooks.ts`；`src/render/drawWeaponAppearance.ts`；`src/plugins/services.ts`（`WeaponLookService`）；`src/meta/bTier/weaponLookData.ts`（长夜种子） |
| **判定（招式盒）** | `ctx.attacks.add`；外功 `SkillDef.attackKey`；行为 `meleeAttack.attackKey` | `AttackBoxDef` = `AttackDef & { id }` | `getAttackBox(id)`；玩家 `castSkill`；敌人 `behaviorInterp` / `loadout` | `src/meta/bTier/types.ts`；`src/meta/bTier/coreData.ts`（`CORE_ATTACK_BOXES` 自 PM/BARE 挂 id）；`src/meta/contentRegistry.ts`；`src/entities/player.ts`（`castKind==='attack'`） |
| **手感** | `WeaponDef.weight` + 可选 `feel`；基线 `damage/speed/reach/poise/rage/airHover` | `WeaponWeight` 闭集；`WeaponFeel` 乘区 | `weightFeel` + `scaleAttack`；取消窗 `chainCancelFrame` / `chainOpenFrames` | `src/meta/weapons.ts`；`src/combat/weaponRuntime.ts` |
| **普攻套路** | `AttackChainStyle`（attackKeys）+ 盒种子 `PM`/`BARE` | Style 软引用 `ctx.attacks` id；物理 cue 在盒上 | `chooseAttack` 读 Style → `getAttackBox`/`SEED_BY_NAME` → `doAttack` | `playerMoves.ts`（Style 种子）；`player.ts` |
| **外功** | `ctx.skills.add`：`castKind` + `attackKey` + `castFx` + `castAnim` + 可选 `attackChain` | `SkillDef`；`castFx`→ScriptStep；`castAnim`→AnimStep/id | `Player.castSkill`：`getAttackBox` 开盒；`talismanScripts.playSteps`；`animScripts.playCastAnim` | `src/meta/skills.ts`；`src/entities/player.ts`；`src/meta/animScripts.ts`；`src/meta/talismanScripts.ts` |

### 1.1 外观解析优先级（已落地）

1. `WeaponDef.parts`（内联）  
2. `WeaponDef.lookId` → `ctx.weaponLooks`  
3. 回退 `shape` / `length` / 三色 / `sprite`（`sheetId` ∈ `ctx.sheets`）  
**禁止 URL**（`appearanceFromWeapon` 对 `lookId` 拒 `http(s)://`）。

### 1.2 外功与武器衔接（已落地）

| 字段 | 作用 | 与武器关系 |
| --- | --- | --- |
| `weaponGate` | `bare\|blade\|spear\|heavy\|any` | 按装备 `category` 门控 |
| `attackKey` | 软引用 `ctx.attacks` **仅**；缺 id →「招式未备」soft-skip（W1 已去裸 BARE 旁路） | 盒本身不绑某把刀；数值仍经装备 `scaleAttack`（普攻路径）或外功自带伤害×熟练度 |
| `castFx` | 结算/特效 ScriptStep（可含 damage*） | 与兵器外观无关 |
| `castAnim` | 观感 AnimStep；默认真伤 | 可与 castFx 同播（`playSkillAnim`） |
| `attackChain` | 多段 AttackBox 目录 id 链（W1：经 `getAttackBox`；缺则 soft-skip） | 种子仍源自 BARE 名=id；普攻链目录化见 W3 |

### 1.3 Schema / 设计台字段（武器相关）

| 源 | 闭集 / 字段 |
| --- | --- |
| `src/plugins/schemas.ts` | `WEIGHTS` light\|medium\|heavy；`CATEGORIES` bare\|blade\|spear\|heavy；`SHAPES` sword\|dagger\|axe\|spear\|twin\|greatsword；`AFFINITIES`；`WeaponSchema`（含 `feel`/`lookId`/`parts`/`sprite`）；`WeaponLookSchema` + `validateWeaponLookParts`；`SkillSchema.attackKey/castFx/castAnim/attackChain` |
| `dlc-server/public/assets/designer-schema.json` | `bladeShapes`；`weaponLooks.parts` 白名单；tag `weapon` / `skill` |

## 3. 目标态

| 角色 | 做 | 不做 |
| --- | --- | --- |
| **内容包** | `ctx.weapons.add` + 可选 `weaponLooks` / `attacks` / `skills` / `sheets`（`./art/`） | 不改战斗 TS；不扩闭集 kind；不挂任意 JS/Canvas/外链 |
| **A 核心** | 单一解释器：读目录缩放普攻、播外功、画外观 | 不按内容 id / 新 shape 名开分支 |
| **C 档** | 仅当缺原语时扩白名单（新 `WeaponVisualPart.kind`、新 weight 档、新普攻链槽位 schema 等） | 不为「多一把刀」开 C 单 |
| **运行时** | 缺 `attackKey` / `lookId` → soft-skip / 回退（与现规格一致） | 不因缺数据抛死 |

目标句：**加一把「雨枪」= 只登记 WeaponDef（+ look 配方）+ 需要时登记 AttackBox / Skill；零战斗文件 diff。**

## 5. 不做 / 暂缓

- 任意 JS / Canvas / 外链 URL / 自由 PNG（sheet 仍 `./art/` + `ctx.sheets`）
- 不顺手改敌人 Boss 壳、`bodyAttacks` 迁目录、gargoyle 负载（属机体积木/敌线）
- 本蓝图阶段**不部署**、不 bump 玩家存档
- 不把「多一把外观刀」做成 C 档扩 shape（优先 look 积木 + feel）
- 暂缓：自由连招图 DSL、按武器 id 的核心永久分支、Arena/导演无关项
