## 终点（用户）

新「精英词条 / 称号 / 残页 / 防具套装与单件 / 场地词缀 / 兵器词缀 / 材料 / 丹药 / 内功」= 内容包只登记数据，且**设计台可编可导出**（远程灌管**已通**）：

- `eliteMods.add`（`EliteModDef`：闭集数值/旗标 + 可选 `weaponCounters`）
- `titles.add`（`TitleDef`：文案 + 极瘦 QoL 字段）
- `fragments.add`（`FragmentDef`：`tag` 闭集五 + 闭集效果字段）
- `armorSets.add` / `armorPieces.add`（套装先于单件；`slot` 闭集七）
- `affixes.add` / `wepAffixes.add`（场地词缀字段面中胖；兵器词缀瘦）
- `materials.add` / `pills.add` / `neigong.add`（材料最瘦；丹 `effect` / 内功 `effects` 数组较胖）

远程 `content.json` / 设计台导出同构可灌（`DlcContentBody` + `applyContent` **已有**上列键）。  
**默认不扩** Schema 闭集 / 效果词汇；**不改**战斗解释器。  
禁止任意 JS / Canvas / 外链 / 自由 PNG。

对照已闭环设计台半边：weapons / skills / talismans / enemies / stages / attacks / poses / fxRecipes / projectiles / volleys / sheets / sfx / backdrops / combatStyles / bossMoves / bossKits …——本线补**玩法副目录空洞**（债 #2）。

### 1.3 Schema / 闭集 / 复杂度粗摸

| 目录 | Schema | 闭集 / 硬点 | 复杂度 | 依赖 |
| --- | --- | --- | --- | --- |
| eliteMods | `EliteModSchema` | 数值/旗标开放；`weaponCounters.category`∈兵器类别闭集 | **瘦～中**（可选 counters 数组） | 可选 `summonEnemyId`→enemies |
| titles | `TitleSchema` | 无闭集枚举；QoL 三可选数字 | **极瘦** | 无 |
| fragments | `FragmentSchema` | `tag`: **qi\|body\|speed\|sustain\|curse** | **瘦** | 无（效果字段闭集） |
| materials | `MaterialSchema` | `weight` 必填；`rare?` | **极瘦** | 无；**被** pills/weapons/neigong/talismans 消耗引用 |
| armorSets | `ArmorSetSchema` | `slots[]`∈**七槽**；`two`/`full` 数值包 | **中**（嵌套 bonus） | 无；**被** pieces/loot `setId`、act `setLean` 引用 |
| armorPieces | `ArmorPieceSchema` | `slot`∈七槽；`base` 必填 | **瘦～中** | 语义挂套装（掉落时 `setId`，非 Def 必填字段） |
| wepAffixes | `WepAffixSchema` | 六可选乘区数字 | **瘦** | 无 |
| affixes | `AffixSchema` | 大量可选闭集效果字段；`evolveTo` 软引用其它 affix | **中胖** | `evolveTo`→affixes；stage `affixBias` |

| neigong | `NeigongSchema` | `effects` 四必填数组 + 签名上限 | **胖** | `meditateCost`→materials |
| acts | `ActPoolSchema` | `kit`/`tint` lit；权重 dict | **中** + **序列化形状未定** | eliteMods / armorSets / materials / weapons / bossKits |

## 3. 目标态

| 角色 | 做 | 不做 |
| --- | --- | --- |
| **内容包** | 十键 `add`；远程 JSON 同构（已能）；设计台导出同构 | 不改战斗 tick/掉落原语实现；不扩闭集；不挂任意 JS |
| **A 核心** | 既有目录 + 解释器；缺 id soft-skip | 不按内容 id 开分支；不为「多一种毒雾颜色」开新效果字段 |
| **C 档** | 仅当缺效果原语时扩 Schema | 不为「设计台编已有目录」开 C 原语单 |
| **设计台** | 能编十键并导出；datalist 弱挂关卡/craft/loot/evolveTo | 不做完整掉落模拟器、不做丹药战斗预览器、不默认开 acts 幕池 UI |

目标句：**加一条「铜皮变种 / 裂气残页别名 / 夜行套装调参」= 设计台登记 + 导出 → 馆 enable 已有 `applyContent` 可灌；零战斗解释器 diff；零存档 bump。**

## 4. 分期建议（D1–Dn）

建议原则（采纳债清单并据调研微调）：

1. **先瘦后胖**：flat 字段（精英/残页/称号/材料/兵器词缀）→ 中等嵌套（套装/单件/场地词缀）→ 胖嵌套（丹 effect / 内功 effects）。

3. **远程已通**：无注入风险；验收路径短（设计台 → export → 既有 applyContent）。
