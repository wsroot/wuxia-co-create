## 外功旁路如何删/改

1. **玩家** `castSkill(castKind==='attack')`：原 `getAttackBox(key) ?? BARE[key]` → **仅** `getAttackBox(key)`；仍无则飘字「招式未备」且不耗内力。
2. **玩家** `attackChain` 续段：原 `(BARE)[nextKey]` → `getAttackBox(nextKey)`；缺则「招式未备」并结束链。
3. **敌人** `loadout` 外功：同样去掉 `?? BARE[key]`；缺盒 `warnOnce` + 拉长 CD 跳过。
4. **种子不变**：`CORE_ATTACK_BOXES = PM/BARE/… map boxFrom`（`id = name`）仍由 `CoreCombatCatalog` 挂进 `ctx.attacks`，故既有 `daomang` / `huzhua2` 等外功无需改 id。
