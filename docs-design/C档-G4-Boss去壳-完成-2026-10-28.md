## 姿态解析（最终规则）

**攻击（`state==='attack'`）**

```
getPose('garg.' + atk.def.name)  →  GARG_ATTACKS[name]  →  GARG_ATTACKS.claw1
```

再经 `attackPose(atk, set, softIdle)`。

**单帧 idle / walk / fly / charge / …（目录 idle 映射）**

```
getPose('garg.' + key)?.strike  →  GP[key]
```

（`softGp`；CORE 未登记 `garg.idle` 等时行为与改前一致；内容包可登记三帧 PoseDef，运行取 strike。）

**勿用**：`getAttackPose` 作 Boss 主路径（缺 id → `slash1`）。
