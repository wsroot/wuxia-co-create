## C 档拟增（优先还目录，少永久核心债）

1. **`ColliderProfile`（`ctx.colliders`）**  
   字段白名单：`id`, `w`, `h`, 可选 `hurtInset` / `gravityScale`。  
   Schema 拒非法；解释器只设 `Body` 尺寸。  
   *替代* `body` 决定的物理盒基线。

2. **攻击盒目录已有雏形 `AttackBoxDef`**  
   把 `bodyAttacks` 迁为 core 配方登记；BehaviorStep `meleeAttack`/`useLoadout` 只引用 `attackKey`。  
   缺 id → soft-skip（与现规格一致）。

3. **`EnemyDef` 组装键（目标形）**  
   必填：`silhouetteId` + `behaviorId` + `colliderId`（或内联 collider 对象，二选一，Schema 互斥）。  
   **废弃必填 `body`**：兼容窗内 `body` 仅作「解析到内置配方 id」的软别名，一版后删。

4. **Boss**  
   `isBoss` + `bossMoves` 仍白名单 kind；导演调用同一 `makeEnemy`/`assembleEnemy`，取消 gargoyle 刷怪旁路。  
   `perch`/`takeoff` 仍暂缓（石兽骨架）。

5. **Draw**  
   不新开自由骨骼 DSL；继续 `baseRig` 闭集 + `SilhouettePart`。若需新外观 kind → 另开 C 单独立项。
