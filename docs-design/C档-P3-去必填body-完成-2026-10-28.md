## body 如何变为可选软别名

1. **Schema**：`body` 仍限闭集 `axe|shield|archer|spear|gargoyle`，但不再 `.required()`。
2. **有 body**：兼容窗路径——继续解析到内置 collider / behavior / draw kit（与 P0–P2 相同）；不强制再填组装键。
3. **无 body**：组装从 `silhouetteId` → `behaviorId` → `colliderId`|内联 `collider`（及 CORE 默认）解析；`CORE_ENEMIES` 仍可带 body 作示范，Schema 不强制。

## pack 校验加严（`validateEnemyAssembly`）

无 `body` 时必须同时满足，否则拒登并 warn：

1. **碰撞**：有效 `colliderId`（非空字符串）**或**内联 `collider`（`w/h ≥ 1`）
2. **长相**：非空 `silhouetteId`（可引用 CORE 剪影 id 作合理默认）
3. **怎么打**：非空 `behaviorId`（可引用 CORE 行为 id 作合理默认）

有 `body` 时跳过上述加严（软别名兼容）。不新建 kind。

## 「石像夜巡」最小配方样例

> 字段清单 + 示例。**不要**实现 perch/takeoff；**不要**新建第二石像 class；运行时仍走 `makeBoss` → `Gargoyle` 壳。可复用 CORE `gargoyle` 剪影/碰撞，或自挂 collider。

### 字段清单

| 字段 | 必填？ | 说明 |
| --- | --- | --- |
| `id` | 是 | 如 `shixiang_yexun` |
| `name` | 是 | 如「石像夜巡」 |
| `hp` | 是 | Boss 底气血（再乘舞台 `hpScale`） |
| `isBoss` | 是（Boss） | `true` → 走 `makeBoss`，勿用 `makeEnemy` 刷 |
| `silhouetteId` | 无 body 时是 | 长相；可 `'gargoyle'` 或自建剪影 id |
| `behaviorId` | 无 body 时是 | 怎么打；CORE `gargoyle` 条目可无 steps（AI 仍 Gargoyle+bossMoves） |
| `colliderId` / `collider` | 无 body 时二选一 | 碰撞；可 `'gargoyle'`（CORE 70×130）或内联 |
| `body` | 否 | 兼容软别名；本样例**省略** |
| `eliteEligible` | 建议 `false` | Boss 通常不精英化 |
| Boss 招式 | 另登记 | `ctx.bossMoves` / `ctx.bossKits` 加权既有 kind（claw/charge/…）；**勿**扩 perch/takeoff |

### 示例 JSON（content.json 片段）

```json
{
  "enemies": {
    "shixiang_yexun": {
      "id": "shixiang_yexun",
      "name": "石像夜巡",
      "hp": 900,
      "isBoss": true,
      "eliteEligible": false,
      "silhouetteId": "gargoyle",
      "behaviorId": "gargoyle",

```

### 示例 TS（Cordis 内容包）

```ts
// 可选：自挂碰撞（与 CORE gargoyle 等价亦可省略自建、直接 colliderId:'gargoyle'）
ctx.colliders.add({ id: 'shixiang_box', w: 70, h: 130, label: '石像夜巡盒' });

ctx.enemies.add({
  id: 'shixiang_yexun',
  name: '石像夜巡',
  hp: 900,
  isBoss: true,
  eliteEligible: false,
  silhouetteId: 'gargoyle',   // 长相
  behaviorId: 'gargoyle',     // 怎么打（壳仍 Gargoyle + bossMoves）
  colliderId: 'shixiang_box', // 碰撞；或内联 collider: { w: 70, h: 130 }
  // 无 body —— P3 组装键路径
});

// 舞台 Boss 刷怪：bossId: 'shixiang_yexun' → director.makeBoss(...)
```

内联碰撞写法：

```ts
ctx.enemies.add({
  id: 'shixiang_yexun',
  name: '石像夜巡',
  hp: 900,
  isBoss: true,
  eliteEligible: false,
  silhouetteId: 'gargoyle',
  behaviorId: 'gargoyle',
  collider: { w: 70, h: 130 },
});
```
