## 终点（用户）

新 Boss「怎么凶」= 内容包只登记数据：

- `bossMoves.add`（`BossMoveDef`：id → 白名单 `kind` + 可选 radius/damage/…）
- `bossKits.add`（close/far 加权表，只引用已登记 move id）
- `enemies.add({ isBoss, silhouetteId, behaviorId, colliderId, **kitId?** })` + 关卡 `bossId`
- 远程 `content.json` / 设计台导出同构可灌、可跑（导演读 kit → `chooseMove` → `getBossMove` → kind 原语）

**保留** `Gargoyle` 作为 A 档解释器/运行时壳（不新建第二石像 class；不为每个 Boss 新建 class）。  
**默认不扩** `BossMoveKind`；**明确暂缓** `perch` / `takeoff`。  
禁止任意 JS / Canvas / 外链 / 自由 AI DSL。

对照杂兵已走：`Behavior` + `silhouettes` + `colliders` + `attacks` 目录；Boss 仍壳内硬绑 AttackDef / `GP`·`GARG_ATTACKS` / 状态机，且 kit 挂接断链。

## 边界（与 Behavior / bodyAttacks / poses·fx / 功法符咒）

| 线 | 管什么 | 本蓝图 |
| --- | --- | --- |
| **Boss 去壳 / bossMoves 专线（本单 G）** | `BossMoveDef` 交付面、kit 挂接、Gargoyle 壳内硬引用收敛、设计台「怎么凶」 | 分期 G1–Gn |
| **敌人 Behavior（B1–B4 已收口）** | 杂兵 `BehaviorStep` / 远程 behaviors | **不抢**；不把 Boss AI 强塞进 BehaviorSteps |
| **bodyAttacks（A1–A4 已收口）** | 杂兵近战盒目录化 | **不抢**；Boss 本地 `CLAW1`… 另期浅迁可点名 |
| **fxRecipes + poses（X1–X5 已收口）** | 通用姿态/特效远程+设计台 | **不抢** X 语义；本线可吃 `garg.*` 已入 `CORE_POSES` 的软引用 |
| **功法 F / 符咒 T / 武器 W** | castAnim / ScriptStep / CombatStyle | **不顺手改** |
| **机体积木 P0–P3（已收口）** | Collider / 通用 Enemy / `makeBoss` 组装 / 去必填 body | **不重开**；本线吃其 `makeBoss` 旁路，继续去壳 AI/绘制硬绑 |

共用但本线可深改 Boss 侧：

- `makeBoss` → `Gargoyle` 壳；`bossMoveWeights(kit)` → `getBossMove` → `chooseMove` switch(kind)。
- `CORE_POSES` 已含 `garg.*`（自 `GARG_ATTACKS`）；绘制层仍直读本地 `GP`/`GARG_ATTACKS`。
- 示范包 `shixiang`：登记 kit / Boss 敌寇，**不扩 kind、不实现 perch/takeoff**。

### 1.2 BossMoveKind 白名单（10 · 暂缓 2）

定义：`src/meta/bTier/types.ts` → `BossMoveKind`。  
Schema：`BossMoveSchema.kind` lit 同表（**无** perch/takeoff）。

| 组 | kind |
| --- | --- |
| 基线 | `claw` · `charge` · `fireball` · `dive` · `roar` · `walk` |
| C 档已扩 | `slam` · `sweep` · `summonAdds` · `inkNova` |
| **暂缓** | `perch` · `takeoff`（注释：石兽骨架暂不支撑；docs 暂缓项 #1） |

`BossMoveDef` 可选字段：`radius` / `damage` / `hitstop` / `width` / `enemyId` / `count` / `side` / `frames` / `color` —— slam/sweep/summonAdds/inkNova 运行时读 `moveParams`；claw/charge/dive/roar/fireball **基本忽略** catalog 字段，走本地 AttackDef。

### 1.3 `ctx.bossMoves` / `ctx.bossKits`（Service）

| 项 | 符号 / 行为 |
| --- | --- |
| Move Service | `BossMoveService`：`super(ctx, 'bossMoves', true)`；`BossMoveSchema` |
| Kit Service | `BossKitService`：`super(ctx, 'bossKits', true)`；`BossKitSchema`（`move` 为裸 string，**不**校验 move 是否在 bossMoves 目录） |
| 查询 | `getBossMove` / `listBossMoves`；`getBossKit` / `listBossKits` / `bossMoveWeights` |
| 长夜注入 | `CoreCombatCatalog`：`CORE_BOSS_MOVES`；`CoreBossKits`：`CORE_BOSS_KITS` |
| Smoke | bossMoves **10**；bossKits **4**；`getBossMove('dive')`；`bossMoveWeights('stone',…)`；缺 kit → walk |

### 1.4 Gargoyle 实体壳（组装 + AI）

| 步骤 | 文件 | 行为 |
| --- | --- | --- |
| 判定 Boss | `factory.isBossArchetype` | `isBoss` \| `body==='gargoyle'` \| type==='gargoyle' |
| 刷 Boss | `makeBoss` | `new Gargoyle(x, params)`；套 collider；挂 `archetypeId`/`silhouetteId`/`behaviorId`（**AI/绘制仍不用后两者**） |
| 误刷杂兵 | `makeEnemy` | Boss 软别名 axe + warn（P2 已收） |
| 导演 | `director.enterBoss` | `kit: pool.kit`（actPools 的 stone/rain/tomb/night），**忽略**敌寇自带 kit |
| 选招 | `Gargoyle.chooseMove` | `bossMoveWeights(this.kit)` → `getBossMove(pickId)` → `switch(kind)` 开状态 / 起手 AttackDef |
| 状态机 | `gargoyle.update` | intro/idle/walk/attack/charge*/fb*/dive*/roar*/slam*/sweep/inkNova/summonAdds/recover/…（约 **31** 个 unique case） |
| 相位 | phase 1→2 | 本地阈值；phase2 `fast(CLAW*)`；霸体等硬逻辑 |

`EnemyDef` / 设计台敌寇表单：**无** `kitId` 字段。Stage boss 字段有 `bossId`/`hpScale`/`dmgScale`/`tint`，**无** kit。

### 1.6 本地 `bossMoves.ts`（AttackDef 硬盒 · 易与目录混淆）

路径：`src/entities/boss/bossMoves.ts`（**文件名**与 catalog `bossMoves` 同名）。

导出：`CLAW1`/`CLAW2`/`CLAW3`/`CHARGE_HIT`/`DIVE_BODY`/`DIVE_WAVE`/`ROAR_WAVE`/`FIREBALL` + `fast()`。  
全部为战斗 `AttackDef` 字面量种子（G5：`boxFrom` → `CORE_ATTACK_BOXES`）；运行时经 `getAttackBox`。  
Gargoyle claw 连段与 charge/dive/roar/fireball 命中只认目录 id（常量 `@deprecated` 仅种子/测试）。

## 3. 目标态

| 角色 | 做 | 不做 |
| --- | --- | --- |
| **内容包** | `bossMoves.add`（别名/调参）+ `bossKits.add` + 敌寇/关卡挂 **kit**；远程 JSON 同构 | 不改 `gargoyle.ts` 状态机；不扩 kind；不实现 perch/takeoff；不挂任意 JS |
| **A 核心** | 单一壳读目录权重 + moveParams；缺 move → walk；缺 kit → walk | 不按内容 id 开第二 Boss class；不把 Boss 强行 BehaviorSteps 化 |
| **C 档** | 仅当缺战斗原语时扩 `BossMoveKind`（另开单） | 不为「换一套石兽权重」开 C kind |
| **设计台** | 能编 kit 权重（+ 可选 move 别名）并导出；关卡/敌寇能挂 kit | 不做完整 Boss 战斗预览器；不做自由 AI DSL |

目标句：**加一套「夜巡石像更爱震地」= 登记 BossKitDef（+ 可选 BossMoveDef 调参）+ 挂到 Boss；零战斗状态机 diff；设计台导出 → 馆 enable 可灌可跑。**
