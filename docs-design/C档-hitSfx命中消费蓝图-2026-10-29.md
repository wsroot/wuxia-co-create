## 决策

1. **叠音策略（选定）**：**有白名单 `hitSfx` → 只播该音，不播默认 `hit`/`hitHeavy`**；无 / 非法 / 仅 `src` 未 decode → **保持今日** `hit`/`hitHeavy`。  
2. **白名单**：`hitSfx` 为 **sfx 目录 id**（与既有一致）；`getSfxDef(id)?.synth` 可播则用 `synth`；无条目或仅文件 `src` → soft-skip（当无 hitSfx）。`./art/` 规则仍在 `SfxCatalogService.add`，本刀不扩文件 decode。  
3. **CORE `arrow`**：去掉未消费的 `hitSfx:'arrow'`，使**缺省无 hitSfx → 与今日 bit-identical**（仍 hit/hitHeavy）。作者/包（如 moyu）显式挂 `hitSfx` 才换音。  
4. **接线**：投射物→敌 `applyHit` 传入可选 `hitSfx`；`hitEnemy` 确认命中时按上策二选一。敌弹→玩家：**仅在确认受伤路径**若有白名单 hitSfx 则多播一次（今日本无 hit/hitHeavy，不替代 `hurt`；格挡/弹反/闪避不播 hitSfx）。  
5. **helper**：`resolveProjectileHitSfx(def)` 与 `resolveProjectileAttackKey` 同层（`contentRegistry`）。
