## 终点（用户）

石兽 **dive / fireball / roar** 仍由 kit→`chooseMove`→kind 开状态链（高风险拓扑留壳），但作者可用 **BossMoveDef 白名单只读字段** 调节奏/条数/半径/投射物 id 等，内容包可拼可辨，**无**任意 JS、**无**为内容新建硬编码 class / 第二绘制器。

**不**把三招改成 BehaviorStep 发起；**不**扩 `BOSS_GAP_LOCO_KINDS` 进招；**不**并 drawKind；**不**开 perch/takeoff。

## 2. 目标边界（白名单步/字段）

### 2.1 建议模型（沿 Gsm3/4，不新 DSL）

| 层 | 本线做什么 | 禁止 |
| --- | --- | --- |
| **BossMoveDef soft** | 扩/复用只读字段；壳 case `windFramesFromMove` 同类 helper soft 读；缺省→今日字面量 | 任意 JS 公式；按内容 id 分支 |
| **状态拓扑** | **留壳**：fbRise/Aim/Down、无敌、noGravity、镜头/FX 触发点 | 用 AnimStep/ScriptStep 重写飞行物理；BehaviorStep 发起 dive |
| **命中** | 继续 `getAttackBox` / 投射物 `attackKey`；可选 soft `attackKey`/`projectileId` 字符串 | 新建硬编码 Attack class；扩 drawKind |
| **BehaviorStep** | **不扩** kind；不把三招塞进 `BOSS_GAP_LOCO_KINDS` | 第二套 Boss 行为 DSL |
| **class** | 仍 `Gargoyle` 一壳 | 为内容新建第二石像 / 第二绘制器 |

### 2.2 建议字段表（分期落地；非法 soft 忽略 + clamp）

| 字段 | 复用/新建 | 建议消费 kind | 缺省（今日） | 说明 |
| --- | --- | --- | --- | --- |
| `windFrames` | **复用 Gsm4** | roar（Dfr1）；可选 diveAim 切下阈值（Dfr3） | roar **40**；diveAim 切下 **68**（仍 ÷spd） | 与 charge/slam/sweep 同 helper |
| `frames` | 既有 | roar active；可选 fbRise | roar **44**；fbRise **34** | inkNova/walk 已占语义——文档按 kind 分列 |
| `radius` | 既有 | roar 环 max；dive 落地波半宽 | roar **300**；dive wave 区 **150**（高） | slam/inkNova 已用 |
| `count` | 既有（summon） | fireball 弹数（phase1 基线） | **3**（phase2 仍可用壳内倍率或另字段） | clamp 1…8 |
| `damage` | 既有 | 仅当不用盒时；**优先仍走盒** | — | Dfr 默认**不**用绝对值盖 `gRoar`/`gFire` |
| `projectileId` | **新建 soft string** | fireball | `'fireball'` | 须目录已有；drawKind 仍闭集；缺→今日 id |
| `attackKey` | **可选新建** | dive 体/波、roar 波 | `'gDive'`/`'gDiveWave'`/`'gRoar'` | 缺→今日；soft-skip 无盒 |

**phase2 加速**：默认仍壳内（如 fb `total/gap`、dive `spd`）；若要数据化须单列「phaseMul」另债，**勿塞 Dfr1**。

## 6. 风险与回退

| 风险 | 缓解 |
| --- | --- |
| soft 破坏无敌窗 / 镜头节奏 | 只调时长与半径；**不**数据化 invulnerable 集合；smoke 断言 diveAim/roar 仍 immune |
| `frames`/`windFrames`/`count` 多 kind 语义撞车 | 门派插件 + Schema note **按 kind 分列**；clamp 表写进完成单 |
| `projectileId` 指向无 draw 支持的条目 | 缺 Def soft→`fireball`；drawKind 仍闭集——坏 id 不扩绘制器 |
| 误扩 Behavior 进招 | PR checklist：禁止改 `BOSS_GAP_LOCO_KINDS` |
| 与 Gsm4 `windFrames` 读者冲突 | 同 helper、按当前 `moveParams.kind` 选 fallback；CORE 三地面行仍 omit |

回退：case 忽略新字段 → 今日字面量；CORE 行不挂字段保持 bit-identical。
